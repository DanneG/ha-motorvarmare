# Motorvärmare 0.13.0

## Heater and energy

- **Stop now** sends the off command and checks the switch even if saving the session fails. A failed stop can be retried. Unloading the integration prevents pending updates from restarting the old switch.
- The cable alert waits for a fresh power reading. Existing configurations with optional sensors omitted still work.
- The live graph updates with each reading. Energy data is saved every five minutes and at session changes. A power cut can leave the last interval incomplete.

## Dashboard and calendar

- Stop and extend controls sit above the active heating graph. The multi-car overview offers responsive full cards alongside the existing compact layout.
- Both add buttons use the selected date. Switch between day and week in the expanded calendar.
- One-time departures stay in the calendar for 31 days. New sessions show actual results beside a departure when the match is clear. Older, already deleted departures cannot be recovered.
- Removal controls are larger. Undo is available for one-time departures. Expand the calendar details to read about overlapping times.
- GitHub Actions runs Python and browser tests, including a two-car dashboard, alongside HACS and hassfest checks.

## Upgrade

1. Update in Marketplace or HACS, restart Home Assistant between sessions and refresh the dashboard.
2. For YAML dashboard resources, set the card URL version to `0.13.0`.
3. To replace a fixed two-car layout, add **Motorvärmare – översikt**, select both cars and choose **Responsive car cards**.
