# Motorvärmare 0.13.0

**Heater control.** Stop now attempts to switch the heater off and checks its reported state even when Home Assistant cannot save the session. A successful unload prevents pending updates from restarting the old switch. An unsuccessful switch-off can still be retried.

**Energy and alerts.** The startup cable warning waits for a fresh power reading before counting time below the threshold. Older configurations can omit optional sensors. The live graph continues to update as readings arrive. During ordinary measurement, the integration checkpoints its data every five minutes and saves at important transitions. An abrupt power loss can leave the last interval incomplete.

**Dashboard.** The active session now shows its controls above the timeline and graph. The multi-car overview offers responsive full cards in two columns or a single column according to available width. Existing compact overviews keep their layout.

**Calendar.** Add a departure for the selected date from either add button. The expanded calendar offers day and week views. Previous local one-time departures are retained for 31 days. Newly recorded sessions show their actual results alongside a departure when they can be matched unambiguously. Past departures removed by previous versions cannot be reconstructed. Calendar entries have larger removal controls and an undo option for one-time departures. Overlap details can be expanded when needed.

**Upgrade.** Update Motorvärmare from Marketplace or HACS, restart Home Assistant between heating sessions, and refresh the dashboard. With YAML dashboard resources, update the version in the resource URL to `0.13.0`. To use the responsive layout for an existing fixed stack, select both cars in a single **Motorvärmare – översikt** card and choose **Responsive car cards**.

GitHub Actions now runs the Python and browser tests alongside HACS and hassfest validation, including a two-car dashboard regression test.
