# Motorvärmare 0.13.1

- Each car's calendar opens on today in Home Assistant's time zone. A ring marks today. A filled circle marks your selected date.
- The card and expanded calendar share your selection through sensor updates. **Go to today** returns to the current date.
- Both add buttons show the target day. The save button shows the departure date and time.

Update in Marketplace or HACS, restart Home Assistant between heating sessions and refresh the dashboard. For YAML dashboard resources, set the card URL version to `0.13.1`.
