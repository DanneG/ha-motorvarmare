# Motorvärmare 0.13.1

Each car's calendar opens on the current date in Home Assistant's time zone, even when the next scheduled departure is several days away. Today has a visible text label and a ring. A filled date shows your selection as you browse. The compact and expanded calendars share the selection, and sensor updates keep it in place.

Use the calendar's today button to return from another date. Both add-departure buttons show the day they will open. The save button shows the date and time from the departure form, so you can check them before saving.

Update Motorvärmare in Marketplace or HACS, restart Home Assistant between heating sessions, and refresh the dashboard. If you manage dashboard resources in YAML, update the version in the card URL to `0.13.1`.
